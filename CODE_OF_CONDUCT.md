# Code of Conduct

This project follows the [OWASP Code of Conduct](https://owasp.org/www-policy/operational/code-of-conduct).

In short: be respectful and constructive, assume good intent, critique ideas rather than people, and keep security
discussion responsible. Don't post working exploits against real systems, and don't share anyone's credentials or
infrastructure details.

To report a concern, contact the maintainer privately (see the repository owner's GitHub profile). Don't use a
public issue. Reports are handled confidentially.
