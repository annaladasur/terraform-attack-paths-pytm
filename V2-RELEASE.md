# V2 engineering release

V2 (package0.2.0) corrects supported deny and permissions-boundary behavior, preserves restriction uncertainty, separates verified target reachability from displayed path limits, and inventories every predicted entry-target pair. CLI and service gates reject incomplete verification; list-only legacy helpers do not establish analysis completeness.

Historical benchmark labels/results remain unchanged, including the one-human-labeler limitation and eight disputed proposals. evaluations/v2 records predeclared supplemental known-input checks and a current-version corpus replay, separately from the original blind results. New code was improved against known examples; this release makes no new unseen-repository or production-accuracy claim.

A modeled path is conditional on declared application assumptions. A removed modeled route still requires deployed denial and intended-use testing. Unresolved restrictions and search truncation remain visible; a short or empty displayed path list is not a security clearance.

No new multi-agent system or reinforcement-learning policy is implemented. Agents may help propose changes; independent testing and reviewed promotion govern releases.
